# Capstone - UNO API (CRUD)

## Descripción

Este proyecto implementa el backend del juego UNO en Node.js + Express con una arquitectura de 3 capas (Controllers / Services / Models-DB).
Se implementan operaciones CRUD para:

- Players
- Games
- Cards (se inicializan automáticamente al crear un Game)
- Scores históricos

Además, se incluye una colección Postman en `documents/postman.json`.

---

## Requisitos

- Node.js 18+ (recomendado)
- MySQL 8+
- npm
